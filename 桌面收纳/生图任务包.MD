# 桌面收纳 · 外部生图任务包（规划 §7.2）

> 用途：用户拿着这份文件到外部 AI 生图工具批量生成物品素材；AI（开发侧）负责接入、对齐与返修。
> 额度预算：33 款正式 + 12 次试验/返修 = 45 次单物品候选。

## 0. 流程（四步）

1. **样本先行**：先生成 2 款文具（建议：橡皮 + 铅笔），确认画风、俯视角、轮廓贴合度后再批量。样本计入正式清单，试验消耗计入额度。
2. **按主题批量**：复用同一份风格前缀，逐款独立成图（每款一张）。新主题开始前先出 1 款代表样本确认。
3. **AI 整理接入**：裁切、去背、统一每格像素与透明边距，绑定 itemId 与 shapeId，跑全部朝向的占格自检。
4. **定向返修**：只重生有问题的款；形状变更时同步重验关联关卡。

## 1. 统一风格（所有提示词共用）

**中文风格前缀：**

```
2D 正交俯视视角贴纸，奶油马卡龙色系，粗圆描边，扁平矢量插画风，
表情简洁可爱（两点眼睛 + 微笑小嘴），柔和均匀光照，无投影，无背景（透明底）
```

**English style prefix:**

```
2D top-down orthographic sticker, creamy macaron pastel palette, thick rounded outlines,
flat vector illustration, simple kawaii face (two dot eyes, small smile),
soft even lighting, no drop shadow, transparent background
```

**统一负面约束：** 不要透视/斜视角，不要阴影投射，不要背景/桌面，不要文字水印，不要写实照片风，不要多件堆叠（一张图只有一件物品）。

## 2. 导出与命名规格

- **格式：** 透明 PNG（sRGB），单物品一张。
- **像素：** 1 格 = 128×128 px；画布 = 形状包围格 ×128，四周再加 16px 透明边距（约 1/8 格，给描边留白）。
  - 例：橡皮（2×2 格）→ 内容区 256×256，画布 288×288。
- **朝向：** 只画**基础朝向（0°）**，与第 3 节模板图示方向一致；其余朝向由程序旋转生成，不另出图。
- **轮廓：** 主体填实模板中的 ■ 格，可带圆角/弧度，但**不得越过 · 格边界**（游戏按格子判定碰撞，外形超出会被判「货不对板」）。
- **镂空：** 发绳、甜甜圈的中心孔（2×2 = 256×256 区域）必须**完全透明**，不是白色填充；装饰性小孔请在交付时单独说明（逻辑上不算孔）。
- **命名：** `item_<id>.png`（id 见第 4 节清单，如 `item_eraser.png`），按主题分文件夹：`stationery/ daily/ digital/ beauty/ snack/`。

## 5. 验收清单（接入前逐款核对）

1. 透明 PNG、无背景无投影、单件物品、正交俯视。
2. 轮廓贴合模板：■ 格填满、· 格留空；镂空件中心孔真实透明。
3. 基础朝向与模板一致（程序负责旋转出其他朝向）。
4. 画风与已入库样本一致（同一风格前缀产出）。
5. 命名 `item_<id>.png`，放入对应主题文件夹。
6. 接入后跑「视觉占格 = 逻辑占格」自检（全部朝向），不通过则列入返修清单（附具体图 + 修改提示词）。
