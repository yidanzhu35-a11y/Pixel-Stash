# 桌面收纳

## 游戏产品与开发需求文档

**项目类型：** H5 轻度休闲益智游戏  
**核心玩法：** 网格空间收纳：移动、旋转物品，将它们放进抽屉  
**目标规模：** 50 个难度递进的关卡

整个游戏采用 AI 分步开发（vibe coding），本文描述完整目标，不要求 AI 在一次任务中实现所有功能、关卡和美术。

---

# 1. 产品概述

## 1.1 游戏概念

玩家获得一批桌面物品，需要将它们合理地放进几个抽屉。物品包含文具、数码配件、日用品、梳妆用品、零食等日常用品。

所有抽屉同时开放，物品可以自由旋转、跨抽屉移动或放回托盘。全部物品收好即通关，允许剩余空隙。

## 1.2 核心体验

1. **观察与判断：** 发现物品适合的朝向、边角和抽屉。
2. **逐步打开局面：** 安排好长条或大件后，剩余空间和后续选择更清楚。
3. **整理满足感：** 一批散乱物品逐渐归位，最终形成整齐、可爱的桌面。

## 1.3 视觉方向

采用 2D 俯视视角、奶油马卡龙配色和少量小表情。物品轮廓清楚，抽屉与物品边界容易辨认，优先适配手机竖屏。

---

# 2. 核心游戏规则

## 2.1 抽屉与物品

- 每关包含若干矩形网格抽屉，宽高分别配置。
- 每件物品由相连的占位格组成，具有独立 ID、位置和朝向。
- 同款物品可以在一关出现多件，共享形状与美术，分别移动和判定。
- 所有物品从托盘开始，全部抽屉始终可用。

## 2.2 摆放规则

- 物品的所有占位格必须在同一个抽屉内。
- 物品不能重叠，可以紧贴。
- 放置自动吸附网格；非法落点保留原位置。
- 已放置物品可随时移动、旋转、跨抽屉调整或返回托盘。
- 全部物品进入抽屉即通关。前期抽屉空间可以留有余量，后期加入精确填满关。

## 2.3 旋转规则

每种形状配置可区分的 90° 朝向。点击物品即可切换，对称形状保留有效朝向。

抽屉内旋转按以下顺序处理：

1. 原位置可以容纳时，原地旋转。
2. 原位置放不下时，移动到同抽屉内最近的合法位置。
3. 整个抽屉无法容纳时，以新朝向返回托盘。

## 2.4 游戏节奏

自由尝试、免费取回，不设倒计时和步数限制。每个抽屉的参考布局以 2–6 件为设计目标，保持局部整理的完成节奏。

# 3. 玩家交互

| 操作 | 效果 |
|---|---|
| 拖动物品 | 放入抽屉、调整位置或拖回托盘 |
| 点击物品／旋转按钮 | 切换朝向 |
| 选中后点击空格 | 在目标位置放置 |
| 点击重开 | 重置当前关卡 |
| 点击提示 | 获得当前局面的收纳建议 |
| 通关后继续整理 | 返回布局，自由调整 |

拖动时显示落点预览，合法与非法位置清晰区分。旋转引起挪位或返回托盘时给出说明；通关后展示整理结果并进入下一关。

---

# 4. 提示系统

提示由求解器根据当前布局生成。

- **当前布局可以继续：** 保留已放置物品，展示一件待收纳物品的可行位置与朝向，该建议属于至少一种完整解法。
- **当前布局需要调整：** 提醒玩家重新安排已放置物品，并提供一项经过求解验证的调整建议。

布局变化后更新提示。搜索超时时返回重试状态，与无解结果区分。

# 5. 关卡设计系统

## 5.1 难度维度

| 维度 | 设计变化 |
|---|---|
| 朝向判断 | 从明显的横竖摆放，逐步增加需要比较的朝向 |
| 形状复杂度 | 从矩形和长条，逐步加入阶梯、十字、缺角等轮廓 |
| 形状配合 | 从独立摆放，逐步增加互补拼合和边角利用 |
| 抽屉分配 | 从去向明显，逐步增加物品可进入多个抽屉的情况 |
| 决策关联 | 从局部调整，逐步增加影响其他物品位置的选择 |
| 空间余量 | 从宽松到紧凑，后期加入精确填满 |
| 物品数量 | 在可观察、可操作的范围内增加组合规模 |

`余量 = 抽屉总格数 − 物品总占格数`

难度由以上维度共同决定。每关保留多种正确布局，结合解法数量、关键分配选择和试玩表现定级。

## 5.2 50 关难度安排

全游戏分为十个阶段，每阶段五关。难度整体递增，阶段之间保留适当回落。

| 关卡 | 主要训练 | 难度推进 |
|---|---|---|
| 1–5 | 基础收纳 | 少量矩形和短条、宽松空间，学会拖放、旋转、取回 |
| 6–10 | 朝向判断 | 加入长条与窄长抽屉，需要比较横放和竖放 |
| 11–15 | 边角利用 | 逐一加入简单异形，学习安排凹口和零碎空间 |
| 16–20 | 形状配合 | 多件物品互补拼合，需要为后续小件保留空间 |
| 21–25 | 抽屉分配 | 不同尺寸抽屉共用物品，先判断长条与大件的去向 |
| 26–30 | 联动规划 | 多件物品都有多个去向，一个抽屉的安排影响其他抽屉 |
| 31–35 | 紧凑布局 | 减少余量，组合朝向、异形与分配判断 |
| 36–40 | 精确收纳 | 引入多解的精确填满关，穿插少量余量的巩固关 |
| 41–45 | 综合规划 | 在紧凑空间里连续处理多项相互关联的选择 |
| 46–50 | 综合挑战 | 组合全套空间能力，通过观察、试放和重排完成复杂布局 |

每阶段按“引导 → 应用 → 变化 → 巩固 → 挑战”组织，巩固关可适当放松。教学阶段每次突出一个重点，后期逐步叠加已有能力。

物品主题独立于难度安排。文具、数码、随身日用、梳妆物品、零食可随进程逐渐增加，一个物品首次出现后，后续可在关卡中按需要灵活安排出现；各阶段通过空间关系与选择复杂度形成区别。

# 6. AI 关卡设计、生成与验证

## 6.1 分批设计

全部 50 关由 AI 按10关一批完成设计、配置、筛选、排序和修订。用户提供试玩反馈，AI 据此调整当前批次及后续难度。

每批流程：

1. **确定目标。** 根据第 5.2 节制定10关的学习重点、难度顺序、物品数量、抽屉组合和余量范围。
2. **生成候选。** 从有限物品库选择种类和数量，搜索完整合法布局，保存参考解，再将物品放回托盘。
3. **自动筛选。** 运行求解器、实例校验和重复布局检查，选出符合本批目标的10关。
4. **交付试玩。** 提供可连续游玩的10关，记录完成时间、调整过程、提示使用和卡住的位置。
5. **修订并推进。** AI 调整关卡与顺序，完成回归验证后进入下一批。

## 6.2 求解器

输入：抽屉尺寸、物品占格、允许朝向、当前已放置物品及其位置。

输出：是否可完成、完整参考解、解法数量或计数下限；支持固定部分物品后的条件搜索，用于提示和局部布局分析。

同形且操作相同的物品交换实例 ID，计为同一布局。换颜色、换物品外观或简单镜像的候选需要做重复筛选。

## 6.3 单关验证

每关交付前由 AI 完成：

- 检查物品引用、独立实例 ID 和朝向。
- 求得完整解，并通过游戏规则逐步回放。
- 检查多解情况及典型局部选择，标出需要重新安排的位置。
- 检查物品轮廓与占格、手机尺寸下的显示和操作。
- 记录难度目标、参考解、验证结果及试玩反馈。

程序验证和试玩反馈共同用于关卡排序，逐批形成 50 关难度曲线。

# 7. 美术资产生产

## 7.1 物品与形状库

物品包括文具、数码配件、随身用品和梳妆物品，共用统一画风。

- 基础轮廓采用长短条、矩形、阶梯、十字和缺角等九种形状，按需要少量扩展。
- 形状库以 9–12 种、物品外观以约 20 种作为首版预算。
- 同形状可以对应不同物品，轮廓应自然、容易辨认。
- 每关选用物品库的子集，同款可跨关、同关重复使用。
- 碰撞依据占格数据，美术与逻辑占位保持一致。

## 7.2 AI 生产流程

1. 根据阶段所需的空间能力，提出物品与占格草案。
2. 用占位图制作代表关卡，配少量正式美术样本检查风格和辨识度。
3. 验证后固定本批物品目录、形状和允许朝向。
4. AI 分批制作正式素材，统一比例、配色和透明背景，绑定形状定义。
5. 在游戏中检查全部朝向与占格，复用到后续关卡。

形状稳定后，正式素材与关卡可交替推进。新增或修改形状时，同步验证引用它的关卡。

# 8. 技术与数据结构

## 8.1 数据分层

| 数据 | 内容 |
|---|---|
| 形状库 `shapeId` | 占格、尺寸、允许朝向 |
| 物品库 `itemId` | 名称、美术、所属类别、引用形状 |
| 关卡实例 `instanceId` | 引用物品、初始方向、当前位置与朝向 |
| 关卡 `levelId` | 抽屉、实例清单、难度目标、参考解与验证记录 |

形状、物品和关卡分别维护，通过 ID 引用。运行状态按实例保存，关卡使用稳定 ID。

## 8.2 功能模块

- 抽屉与物品管理。
- 放置与旋转判定。
- 求解器与提示。
- 关卡加载、选关、重开与结算。
- 进度和中途布局存档。
- 绘图、触屏与鼠标交互。

## 8.3 平台要求

H5 网页游戏，优先手机竖屏，兼容桌面鼠标。关卡与素材本地加载，进度自动保存，刷新后可继续整理。

# 9. AI 分步开发计划

AI 负责游戏代码、全部关卡设计、美术生产和验证。每次任务明确输入文件、修改范围、交付物与验收方式，完成后记录结果和下一步。

| 阶段 | 主要工作 | 交付 |
|---|---|---|
| M1：核心原型 | 建立形状、物品与实例数据，完成拖放、旋转、取回、通关；试做美术样本 | 少量可玩关卡，验证基本收纳体验 |
| M2：生产工具 | 完成求解器、提示、候选生成、去重与参考解回放 | 可持续生成和验证关卡的工具链 |
| M3：50 关制作 | 按第 5.2 节分十批设计和制作，每批五关，结合试玩调整难度；同步接入素材 | 50 关数据、共享素材库和验证记录 |
| M4：完整体验 | 完善选关、教学、结算、进度与中途存档，统一视觉与声音 | 连贯的完整游戏 |
| M5：打磨发布 | 测试全部关卡、难度衔接、手机操作与加载性能 | 可发布的 50 关 H5 版本 |

---

# 10. 验收标准

- 拖放、旋转、取回与碰撞规则一致，手机和桌面操作稳定。
- 全部物品收好后正确结算，选关与存档正常。
- 提示基于当前局面，建议能够通过游戏规则验证。
- 50 关均有完整参考解，支持多种正确布局。
- 难度整体递进，阶段内有引导、变化和挑战。
- 物品与形状充分复用，关卡具有不同的空间规划重点。
- 美术轮廓清楚，全部朝向与逻辑占格一致。
