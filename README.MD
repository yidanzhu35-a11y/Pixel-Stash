## 运行

直接双击各目录的 HTML 可以试玩。建议开发时统一用本地服务，以保持浏览器存档所在的来源一致；file:// 与 HTTP 下的存档未必互通。

在根目录的 PowerShell 中运行：

```powershell
powershell -NoProfile -File .\tools\serve.ps1
```

若同一项目的 8642 服务已启动，不需要重复启动。打开 <http://localhost:8642/>，进入“桌面收纳”。旧书签里的 `packing/`、`积木收纳大师-packing/`、`文具收纳/` 已不对应整理后的目录，请使用本导航里的入口。
